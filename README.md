# Python lab 2
____
## Условие задачи:
### Задание 2.
Реализовать длинную арифметику для целых чисел с операциями сложения, вычитания, умножения и целочисленного деления.
Задаться основанием системы счисления M и максимальной разрядностью N в M-ричной системе счисления и реализовать перечисленные операции для представлений длинных чисел в этой системе счисления.

В программе используются M = 1000 и N = 100. Программа в цикле запрашивает два числа и выводит результаты операций `+`, `-`, `*`, `//`, `%`. Для выхода введите `q`.
____
## Описание решения
____
- Число хранится как пара: знак (`1` или `-1`) и список разрядов в системе с основанием `M`, от старшего к младшему.
- Основание `M` может быть любым целым числом от 2 и больше (например, `10**6`), ограничения в 36 нет: ввод всегда десятичный, а разряды хранятся как обычные числа `int`.
- При выводе разряды разделяются пробелом, например `123 456 789` для `M = 1000`.
- Деление выполняется в столбик, цифра частного подбирается двоичным поиском.
- Частное округляется к нулю, остаток имеет знак делимого, так что всегда `a = q * b + r`. Поэтому результат отличается от `//` и `%` в Python для отрицательных чисел: `-7 // 2 = -3` и `-7 % 2 = -1` (в Python `-4` и `1`).
- Ввод, отличный от целого десятичного числа, пустая строка или число длиннее `N` разрядов вызывают сообщение об ошибке, и число запрашивается заново. При делении на ноль выводится ошибка.

| Функция | Описание |
|---|---|
| `from_string(s)` | Строка → `(sign, digits)` |
| `to_string(sign, digits)` | `(sign, digits)` → строка |
| `add`, `subtract`, `multiply` | Сложение, вычитание, умножение |
| `divide` | Частное и остаток: `(sign_q, quotient, sign_r, remainder)` |

## Установка виртуального окружения и запуск
____
### 1. Клонируйте репозиторий
```bash
git clone https://github.com/Syntax-Error-Squad/task-2-bignum-arithmetic.git
cd task-2-bignum-arithmetic
```
### 2. Создайте виртуальное окружение
```bash
python -m venv venv
```
### 3. Активируйте виртуальное окружение
- **Windows CMD**
```bash
.\venv\Scripts\activate
```
- **Windows PowerShell**
```powershell
.\venv\Scripts\Activate.ps1
```
- **macOS/Linux**
```bash
source venv/bin/activate
```
После активации виртуального окружения в командной строке появится префикс venv.
### 4. Запустите программу
```bash
python task_2_bignum_arithmetic.py
```
Числа вводятся слитно, без пробелов (`123456789`, а не `123 456 789`). Пробелы между разрядами появляются только при выводе.

Пример работы:
```
Введите первое число: 123456789
Введите второе число: -987

Первое число: 123 456 789
Второе число: -987

123 456 789 + -987 = 123 455 802
123 456 789 - -987 = 123 457 776
123 456 789 * -987 = -121 851 850 743
123 456 789 // -987 = -125 082
123 456 789 % -987 = 855
```
